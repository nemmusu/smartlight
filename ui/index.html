Server MCP

CARICAMENTO

Collega un assistente alle luci e ai blocchi PC. Smartlight deve restare aperto, anche nell’area di notifica.

1

Indirizzo HTTP

Avvia qui il server MCP Streamable HTTP e copia l’URL nel client. Nessuna finestra terminale.

Usa la LAN solo se è fidata: HTTP e token viaggiano senza cifratura. Windows Firewall potrebbe bloccare la porta 8766.

Indirizzo sulla LAN

Client stdio

Per i client che usano un comando locale. Il client avvia Smartlight-MCP automaticamente quando si collega; aprirlo a mano mostra solo una finestra vuota.

Verifica l’handshake e l’accesso al controller senza cambiare le luci.
Come configurare il client MCP
  1. Apri le impostazioni MCP del tuo client.
  2. Se supporta URL MCP, avvia il server HTTP e incolla URL e token con “Copia configurazione HTTP”.
  3. Se richiede un comando, incolla “Copia configurazione stdio”. Il client avvierà l’eseguibile da solo.

La configurazione copiata è un esempio generico JSON: alcuni client usano nomi di campi diversi.
